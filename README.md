# СОЧ по информатике — 11 класс (1 четверть)

Веб-приложение для 21 ученика, двух вариантов, индивидуальных таймеров 40 минут и учительского журнала.

## Запуск

Требуется **Node.js 20+**. Дополнительные npm-пакеты не нужны.

Linux/macOS:
```bash
cd soch11_site
export TEACHER_PASSWORD='УСТАНОВИТЕ_СЛОЖНЫЙ_ПАРОЛЬ'
export SESSION_SECRET='УСТАНОВИТЕ_СЛУЧАЙНУЮ_СТРОКУ_НЕ_КОРОЧЕ_24_СИМВОЛОВ'
node server.js
```

Затем откройте http://localhost:3000 для ученика и http://localhost:3000/teacher для учителя.

**Важно:** `localhost` виден только на компьютере сервера. Чтобы дать общую ссылку классу, разместите Node.js-приложение на HTTPS-хостинге с **постоянным диском** для `data/state.json`; настройте переменные окружения, `COOKIE_SECURE=1`. Не используйте временный хостинг без сохранения данных. Никогда не публикуйте секреты и содержимое папки `data`.

## Как провести СОЧ

1. Зайдите в `/teacher` с паролем.
2. В учительском журнале уже создан список из 21 ученика; у каждого шестизначный уникальный код. Передайте каждому только его код.
3. Назначение вариантов 1/2 чередуется по списку. До начала работы ученика его вариант можно изменить.
4. Ученики открывают `/`, выбирают своё ФИО, вводят личный код и ждут.
5. Учитель нажимает «Открыть доступ к началу». Каждый ученик нажимает «Начать СОЧ» и с этого момента у него идут **свои 40 минут**. Обновление страницы не сбрасывает отсчёт.
6. Текст сохраняется автоматически во время работы. По окончании срока сервер запрещает редактировать ответы. Ученик может завершить раньше.
7. В `/teacher` открывайте ответы, проверяйте предварительные баллы, при необходимости изменяйте и подтверждайте оценку; затем экспортируйте CSV (открывается в Excel).
8. Кнопка «Публиковать результаты» показывает ученику его балл. Не публикуйте до подтверждения всех работ.

## Важные границы автоматической проверки

По умолчанию включена **приблизительная проверка по ключевым словам и смысловым индикаторам**. Она не распознаёт всех правильных формулировок, особенно объяснения и схему; итоговые баллы должен подтвердить учитель.

При заданном `OPENAI_API_KEY` дополнительно вызывается API модели (по умолчанию `gpt-4o-mini`), и оценивание выполняется по всем дескрипторам с учётом смысла ответа. Это **предварительная оценка**, не гарантирует объективности или точности. Текст ответа ученика при этом отправляется внешнему провайдеру: используйте только при наличии необходимых разрешений и соблюдении правил обработки данных учащихся. ФИО в запрос оценки не включается. Не добавляйте ключ в браузер.

Для задания 1а представлен наглядный шаблон сети, а ученик самостоятельно описывает структуру в ответе. Это не графический редактор схемы.

## Данные и безопасность

- Состояние класса и оценки хранятся в `data/state.json`; обеспечьте резервное копирование и доступ к файлу только администратору.
- Коды учащихся предотвращают случайный вход под чужим именем; их нужно раздать конфиденциально.
- Перед публичным развёртыванием рекомендуется добавить ограничение частоты попыток входа, HTTPS, резервные копии, управление повторными попытками и отдельную проверку безопасности.
- Таймер проверяется на сервере; при истечении 40 минут сохраняются **последние успешно отправленные** ответы. Если ученик потерял интернет непосредственно перед дедлайном, несохранённые данные могут потеряться.
- В этой версии оценивание уже завершившей работы запускается в процессе сервера; при его перезапуске во время запроса ИИ останется локальная предварительная оценка.
